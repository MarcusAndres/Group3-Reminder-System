## Reminder Management System

The Reminder System is a program that helps users organize and manage their schedules by setting reminders for important tasks, activities, and events. It allows users to create, view, update, and delete reminders, making it easier to keep track of responsibilities and avoid missing important commitments. The system also provides notifications when a reminder is due, helping users stay organized and manage their time effectively.

This project was developed as a school activity to demonstrate the application of programming concepts such as data management, time-based functions, user interaction, and CRUD (Create, Read, Update, Delete) operations. It serves as a practical example of how programming can be used to create useful tools that address everyday needs while strengthening problem-solving and software development skills.

## Features (CRUD)

### Create

* Add new reminders using hour, minute, AM/PM, and customizable message inputs.

### Read

* View all reminders in chronological order.
* Display the three nearest upcoming reminders.
* View the current system time.

### Update

* Double click a reminder to edit its time and message.

### Delete

* Remove selected reminders using the Delete button.

### Additional Features

* Live digital clock that updates every second.
* Automatic notification popup when a reminder becomes due.
* Upcoming reminder countdown display.

## Instructions on How to Use the Reminder System

### 1. Launch the Program

Run the Python file to open the Reminder Management System. The current time will be displayed at the top of the window and will update automatically every second.

### 2. Add a Reminder

1. In the **Add Reminder** section, select:

   * Hour (1–12)
   * Minute (00–59)
   * AM or PM
2. Enter the reminder message in the text field.
3. Click **Add Reminder**.
4. The reminder will be added to the system and displayed in the reminder list.

### 3. View Upcoming Reminders

The **Upcoming Reminders** section displays the three nearest reminders. These reminders are automatically sorted based on how soon they will occur and show the remaining time until they are due.

### 4. View All Reminders

The **All Reminders** section displays every reminder stored in the system. Reminders are automatically sorted chronologically from **12:00 AM** to **11:59 PM**.

### 5. Edit a Reminder

1. Double-click a reminder in the **All Reminders** list.
2. An edit window will appear.
3. Modify the time or message as needed.
4. Click **Save** to apply the changes.

### 6. Delete a Reminder

1. Select a reminder from the **All Reminders** list.
2. Click the **Delete** button.
3. The selected reminder will be permanently removed from the system.

### 7. Notification System

When the current time matches a scheduled reminder, a notification window will automatically appear displaying:

* The reminder time
* The reminder message

Click **Dismiss** to close the notification.

### Notes

* Reminders are checked every second.
* Multiple reminders can be scheduled for the same day.
* The upcoming reminders list updates automatically as time progresses.
* Closing the program will remove all reminders unless a save feature is implemented.
